# Prompt — Estratégias de Resposta aos Riscos

## Contexto fornecido à IA

O prompt abaixo foi utilizado para solicitar à IA a elaboração das estratégias de resposta para cada risco identificado e analisado.

---

## Prompt Utilizado

```
Com base nos 10 riscos identificados e analisados (RSK-01 a RSK-10), 
elabore estratégias de resposta para cada um.

Para cada risco, apresente QUATRO estratégias:
1. Evitar — eliminar a causa raiz ou alterar o plano
2. Mitigar — reduzir probabilidade e/ou impacto
3. Transferir — deslocar responsabilidade ou impacto para terceiro
4. Aceitar — reconhecer sem ação proativa

Após apresentar as quatro opções, indique:
- Qual estratégia é RECOMENDADA para este projeto específico
- Justificativa da recomendação
- Ações práticas para implementação (3 a 5 ações por risco)

REGRAS:
- As estratégias devem ser viáveis no contexto de uma melhoria de software 
  em ERP hospitalar;
- As ações práticas devem ser concretas e executáveis;
- Considere o escopo limitado do projeto (não é um desenvolvimento completo);
- Ao final, apresente um resumo consolidado com a estratégia recomendada 
  para cada risco.
```

---

## Observações

- A IA gerou estratégias para todas as quatro categorias, mesmo quando algumas eram pouco viáveis, para permitir comparação e análise pelo profissional.
- A estratégia recomendada foi selecionada com base na relação custo-benefício e na viabilidade no contexto do projeto.
- Nenhum risco recebeu a recomendação de "Aceitar" como estratégia principal, refletindo a criticidade do ambiente hospitalar.
